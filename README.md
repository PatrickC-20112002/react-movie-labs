# React Movies App

Web App Development 2 - React Assignment 1

This repository contains my React Movies application, extended from the practical Movie Labs with additional TMDB endpoints, movie searching, filtering, sorting, person profiles, personal lists and reviews.

## Project Documentation

The React application and full documentation are located in the `movies` directory.

**[View the React Movies App README](movies/README.md)**

## Running the Application

```bash
cd movies
npm ci
npm run dev
```

A TMDB API key is required. See the full README for setup instructions.
